# Security Toolkit (WIP)

Scripts de automação focados em hardening e instalação de ferramentas de segurança para sistemas Linux.

## 🛡️ Ferramentas incluídas:
*   **Firewall & Proteção:** Configuração de `ufw`, `firejail` e `openvpn`.
*   **Scanner de Malware/Rootkits:** Instalação de `clamav`, `rkhunter` e `chkrootkit`.
*   **Criptografia:** Setup de `gpg` para assinatura e cifrage.
*   **Monitoramento:** Integração futura com `Wazuh` (Roadmap).
